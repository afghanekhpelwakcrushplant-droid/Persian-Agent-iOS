# Persian Agent — Android foundation

## هدف
این شاخه هسته بومی Android برای دستیار فارسی پروژه را نگه می‌دارد.

## اکنون پیاده شده
- ورودی گفتاری فارسی با fa-IR
- خروجی گفتاری فارسی با Android TextToSpeech
- نرمال‌سازی اولیه فارسی و اعداد فارسی/عربی
- تماس با تأیید صوتی
- ارسال پیامک از طریق صفحه پیام
- جستجوی وب
- یادآور با AlarmManager و Notification
- رابط RTL
- ساخت خودکار APK با GitHub Actions

## مرحله بعد
1. VoiceInteractionService و انتخاب به‌عنوان دستیار پیش‌فرض Android
2. Agent Orchestrator و Tool Router
3. اتصال اختیاری مدل زبانی
4. حافظه و ترجیحات کاربر
5. hotword در دستگاه‌هایی که سیستم/سخت‌افزار اجازه می‌دهد
6. ابزارهای بیشتر: برنامه‌ها، تقویم، فایل، موقعیت، رسانه و خودرو

## قاعده ایمنی
عملیات حساس مثل تماس نباید بدون تأیید صریح کاربر اجرا شوند.
