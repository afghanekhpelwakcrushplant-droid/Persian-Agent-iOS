# Persian Agent — Android
نسخه بومی Android از پروژه Persian Agent.
قابلیت‌های نسخه 0.1:
- تشخیص گفتار فارسی با fa-IR
- پاسخ صوتی فارسی
- Agent محلی برای فرمان‌های قطعی
- تماس با تأیید
- پیامک از طریق صفحه پیام
- جستجوی وب
- یادآور
- رابط RTL
حداقل Android: 8.0 (API 26)
این نسخه بدون API Key برای فرمان‌های محلی کار می‌کند.
