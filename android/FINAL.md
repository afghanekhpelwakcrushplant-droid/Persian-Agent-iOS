# Persian Agent Android — 1.0 foundation

این شاخه نسخه نهایی محصول Android را نگه می‌دارد.

هسته:
- فارسی fa-IR
- TTS فارسی
- Agent محلی
- تماس با تأیید
- پیامک
- یادآور
- جستجوی وب
- باز کردن برنامه‌ها
- حافظه محلی
- VoiceInteractionService
- درخواست نقش Assistant

محدودیت سخت‌افزاری/سیستمی:
Hotword کاملاً بدون تعامل کاربر فقط در دستگاه‌هایی ممکن است که Android/SystemUI و سخت‌افزار یا سرویس تشخیص صوت آن را اجازه دهند. در غیر این صورت ورود به Assistant از مسیرهای رسمی سیستم استفاده می‌شود.
